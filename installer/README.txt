School Theatre Manager
======================

Open it from the shortcut on the desktop or in the Start menu. It opens in your web
browser but runs only on this computer (no internet needed).

Your data lives in C:\ProgramData\School Theatre Manager (the "Data folder" shortcut in
the Start menu). Turn on Cloud backup in Settings > Backups & data to keep a copy in
your school OneDrive or Google Drive.

Forgot the director password? A Windows administrator can run
"Reset Director Password" from the School Theatre Manager folder in the Start menu.

The program runs in the background after you open it. To stop it, use
"Stop ..." in the Start menu folder, or restart the computer.
