SCHOOL THEATRE MANAGER

OPENING IT
  Double-click your theatre program's shortcut on the desktop or in the Start menu
  (Start menu > School Theatre Manager). It opens in your web browser but runs only on
  this computer; no internet is needed. Sign in with the director account created in Setup.

YOUR SCHOOL'S BRANDING
  School name, program name, short name, tagline, logo and accent color are set in Setup
  and can be changed any time in Settings > School & branding.

WHERE YOUR DATA LIVES
  C:\ProgramData\School Theatre Manager
    inventory.db   the database (shows, cast & crew, items, rentals, renters, users)
    photos\        item photos
    showfiles\     show materials and show photos
    branding\      your school's details and logo
    backups\       automatic daily backups (last 30 kept)
    config.json    settings (port, network sharing, cloud backup folder)

CLOUD BACKUP (recommended)
  Settings > Cloud backup > choose your school OneDrive or Google Drive folder.
  The app copies the database, photos, show files and branding there after each change.
  New computer?  Install the program, sign in, set the same folder, click Restore.

ACCOUNTS
  Director   - everything, including users, branding, dropdown lists, backups and deleting records.
  Assistant  - add/edit shows, cast & crew, materials, photos, items, renters,
               rentals and show checkouts.
  Passwords need 8+ characters, a capital letter and a special character.
  Forgot the director password?  Start menu > School Theatre Manager >
  "Reset Director Password" (needs a Windows administrator). It shows a temporary password.

CLOSING IT
  The program keeps running quietly in the background so the browser tab works.
  To stop it: Settings > "Close the program".
