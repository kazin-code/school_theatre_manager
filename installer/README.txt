AHS THEATRE APPLICATION
Alton High School Theatre

OPENING IT
  Double-click "AHS Theatre Application" on the desktop or in the Start menu.
  It opens in your web browser but runs only on this computer; no internet is needed.
  Sign in with the director account you created during Setup.

WHERE YOUR DATA LIVES
  C:\ProgramData\AHS Theatre Application
    inventory.db   the database (shows, cast & crew, items, rentals, renters, users)
    photos\        item photos
    showfiles\     show materials and show photos
    backups\       automatic daily backups (last 30 kept)
    config.json    settings (port, network sharing, cloud backup folder)

CLOUD BACKUP (recommended)
  Settings > Cloud backup > choose your school OneDrive or Google Drive folder.
  The app copies the database, photos and show files there after each change.
  New computer?  Install the app, sign in, set the same folder, click Restore.

ACCOUNTS
  Director   - everything, including users, dropdown lists, backups and deleting records.
  Assistant  - add/edit shows, cast & crew, materials, photos, items, renters,
               rentals and show checkouts.
  Passwords need 8+ characters, a capital letter and a special character.
  Forgot the director password?  Start menu > AHS Theatre Application >
  "Reset Director Password" (needs a Windows administrator). It shows a temporary password.

CLOSING IT
  The program keeps running quietly in the background so the browser tab works.
  To stop it: Settings > "Close the AHS Theatre Application".
